Kerbal Logistics Program is a lightweight resource logistics mod for Kerbal Space Program that allows players to transfer resources between stations and planetary bases through a persistent, location-based mailbox system.

Deposit resources from your vessels, ship them between established locations, and withdraw them wherever they're needed.

Features

Interplanetary resource shipping

Persistent, unlimited virtual resource storage

Automatic station and destination discovery

Support for stock and modded resources

Native KSP toolbar integration

Resizable interface with searchable inventory tables

Live transaction previews and quick-transfer controls

Lightweight, event-driven architecture

No external mod dependencies

No custom parts required

KLP is designed to eliminate repetitive resource hauling without requiring players to abandon their existing infrastructure or install an entirely new resource production system.
